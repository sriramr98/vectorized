## Get the source

Clone the repository and enter the project directory:

```bash
git clone https://github.com/sriramr98/vectorized.git
cd vectorized
```

Download the modules and run the complete test suite:

```bash
go mod download
go test ./...
```

## Start Vectorized

Run the in-memory server on its default port:

```bash
go run . server
```

The process now listens for RESP requests on port `6380`. Stop it with `Ctrl+C`.
