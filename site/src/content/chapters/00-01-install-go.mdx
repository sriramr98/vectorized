## Install Go 1.27

Vectorized uses **Go 1.27**. Install Go 1.27 using the official installer or the version manager you already use.

Confirm that the toolchain is available:

```bash
go version
```

The output should report Go 1.27. We are not changing the version declared in `go.mod` yet; that will be updated separately when the project is ready to adopt the new toolchain.

<div class="invariant-callout">
  <span>CHECKPOINT</span>
  <p>The `go` command is available and reports Go 1.27.</p>
</div>
